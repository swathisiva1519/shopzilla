# ShopZilla - Premium ReactJS E-Commerce Web App

A fully responsive, high-performance E-Commerce application built using ReactJS, Redux Toolkit, and Tailwind CSS.

## Tech Stack & Features
- **Frontend:** ReactJS (Functional Components & Hooks)
- **State Management:** Redux Toolkit (Persistent shopping cart logic)
- **Styling:** Tailwind CSS (Modern, premium UI with responsive design)
- **Data Persistence:** LocalStorage integration to save cart state on refresh
- **Icons:** Lucide React icons
- **Fail-safe Architecture:** Implemented dynamic API handling with resilient local data backup

## How to Run Locally
1. Clone the repo: `git clone <your-repo-link>`
2. Install packages: `npm install`
3. Run the development server: `npm run dev`
